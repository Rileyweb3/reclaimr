# RECLAIMR

Six-page, standalone static project website. Open `index.html` in a browser, or serve this directory with any static web server. No build step or package installation is required. Deploy the entire directory together so relative page and asset links are preserved.

## Pages
- `index.html` — Homepage
- `about.html` — Mission, vision and approach
- `infrastructure.html` — Five proposed ecosystem components
- `roadmap.html` — Four planned development phases
- `whitepaper.html` — Readable overview and downloadable text preview
- `community.html` — Official X and Telegram links

Shared styling and interactions live in `styles.css` and `script.js`. Fonts load from Google Fonts with system fallbacks. The site includes reduced-motion support, mobile navigation, keyboard focus styling and native page transitions where supported.
